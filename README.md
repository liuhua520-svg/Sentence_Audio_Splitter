# 逐句音频切分工具（独立于 SVS-Lab-Tools）

单文件 Tkinter GUI，与 SVS-Lab-Tools 主项目完全独立，不依赖其后端/前端。

## 安装

```bash
pip install numpy soundfile sounddevice
```

`tkinter` 是 Python 标准库自带的（Windows 官方安装包默认包含；Linux 若缺失，
`sudo apt install python3-tk`）。

`sounddevice` 用于"预览播放"功能（基于 PortAudio）。如果这个库没装成功，
或者所在环境没有可用的音频输出设备，点预览播放/按空格时会弹出明确的错误
提示，但不影响打开/编辑/保存/导出/裁剪等其它功能正常使用。

## 运行

两个文件放同一目录下：

```
timeline_core.py   ← 核心逻辑（解析/保存/导出/裁剪，无 GUI 依赖）
splitter_gui.py     ← GUI 入口
```

```bash
python splitter_gui.py
```

## 功能

1. **打开** `.ttslt` / `.dtslt`（SVS-Lab-Tools 输出的序列时间表调试文件）。
2. **导入** `.srt` / `.lrc` / `.lab`，转换成同样的可编辑表格（导入后用"另存为"
   保存成 `.ttslt`）。
3. **编辑**：表格双击单元格可改文本 / 起始秒 / 结束秒（时长自动重算）；
   支持删除行、上移/下移调整顺序。
4. **保存 / 另存为**：写回 `.ttslt`（含句间静音 `{"silence": ...}` 自动补回）
   或 `.dtslt`，未识别的原始字段（如 `phonemes`、`wav_path`）原样保留。
5. **音频只加载一次**：在"音频"区选择一次 wav，"剪掉开头"和"逐句音频导出"
   共用这同一份内存音频，不需要分别选择文件。
6. **剪掉开头**：按 BPM + 拍号算出"一拍"对应的秒数，从**内存中加载的音频**
   头部裁掉 N 拍——只影响内存，不覆盖磁盘上的原始文件；需要单独保留裁剪
   结果时点"另存为新 wav"。

   > 换算公式：一拍秒数 = 60 ÷ BPM ×（4 ÷ 拍号分母）。
   > 例如 BPM120、4/4 拍：一拍 = 60/120 = **0.5 秒**（不是 2 秒）。
   > 界面会实时显示"一拍 = X 秒 → 裁 N 拍 = 共 X 秒"，下刀前请核对。

   > **注意**：裁剪只改音频，不会自动改时间表。如果裁剪后想让每句的
   > 起止时间继续对得上，需要自己在表格里把每行的 `start_sec`/`end_sec`
   > 减去已裁掉的秒数。

7. **逐句音频导出**：选定导出目录后，按 `index` 顺序把"音频"区当前加载
   的音频（如果已经裁剪过开头，用的就是裁剪后的音频）切分导出：
   ```
   {index}_{文本前N字}.wav
   {index}_{文本前N字}.txt
   ```
   `index` 直接用原值展示（1、2、3、10、100……不补零）。若某行的时间区间
   落在裁剪后已经不存在的部分（比如没有同步调整时间表），该行会被跳过并
   在导出完成提示里告知跳过了几行。
8. **预览播放**：选中表格中一行后，点「▶ 播放」按钮，或直接按空格键，
   只播放该行 `[start_sec, end_sec)` 这一段音频，播完自动停；再按一次
   空格/按钮会提前停止播放（开关式）。用的是"音频"区当前加载的内存
   音频——如果已经裁剪过开头，预览的就是裁剪后的结果。
9. **预览进度条 + 从头重播**：
   - 播放过程中进度条实时走动，左侧显示 `当前秒 / 总秒`。
   - **拖动进度条**：即时跳转到新位置并从该处继续出声（约 120ms 节流，
     松开时再精确定位一次）。
   - **「从头重播」**按钮：从该句起点重新播放（不论当前停在哪里）。

## 文件结构说明（供二次开发参考）

- `timeline_core.py` 不依赖 tkinter，可独立单元测试／被其它脚本复用。
- `TimelineDoc` / `TimelineRow` 是内部统一的数据结构，`.ttslt` 的
  `sentences` 和 `.dtslt` 的 `boxes` 都会被解析成同一套 `rows` 列表，
  每行未被识别的额外字段（`phonemes`、`wav_path`、`title` 等）保存在
  `row.extra` 里，写回文件时原样透传，不会丢失。
